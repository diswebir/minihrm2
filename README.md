# مینی HRM — سامانه جامع منابع انسانی، جذب و استخدام

سامانه‌ای کامل، فارسی و راست‌به‌چپ (RTL) برای مدیریت منابع انسانی با **Node.js** که روی **cPanel بدون SSH** نصب می‌شود؛ نصب کاملاً از داخل مرورگر انجام می‌گیرد و در نخستین ورود، **مدیر کل (سوپر ادمین)** تعریف می‌شود.

---

## ✨ فهرست امکانات

### هسته و پایه
- **۲۵ ماژول مستقل** که هرکدام در «تنظیمات → ماژول‌ها» قابل **فعال/غیرفعال** شدن است.
- **۱۰ نقش آماده** (مدیر کل، مدیر منابع انسانی، کارمند منابع انسانی، کارشناس جذب، کارشناس حقوق و دستمزد، مدیر، کارمند، نگهبان/انتظامات، بازرس/حسابرس، داوطلب شغلی) با **۲۱۵ سطح دسترسی** و امکان ساخت نقش دلخواه.
- **۸۶ بخش داده‌ای** (Resource) با فهرست/جست‌وجو/فیلتر/مرتب‌سازی/صفحه‌بندی/خروجی CSV، **سطل بازیافت** و بازیابی رکوردها، و **لاگ کامل عملیات** (Audit Trail).
- **داشبورد اختصاصی هر نقش**، سلف‌سرویس کارمند، تقویم کاری، اعلان‌های درون‌سامانه‌ای و **یادآورهای سررسید**.

### جذب و استخدام (QR + OTP + فرم گام‌به‌گام)
- تعریف **موقعیت‌های شغلی** و مراحل جذب؛ کارشناس منابع انسانی یک **دعوت‌نامه** می‌سازد و **QR** آن را روی صفحه نشان می‌دهد.
- داوطلب با اسکن QR وارد می‌شود، **شماره موبایل + کد یک‌بار‌مصرف (OTP)** را تأیید می‌کند (سرویس پیامک **IPPanel** — قابل تنظیم)، موقعیت شغلی را انتخاب می‌کند و فرم استخدام را **گام‌به‌گام** پر می‌کند.
- **الزامی/اختیاری بودن هر فیلد** از قبل توسط مدیر/کارشناس منابع انسانی تعیین می‌شود (سازندهٔ فرم: افزودن بخش و فیلد، شرطی‌سازی، جابه‌جایی، تغییر نوع، فعال/غیرفعال).
- پیش‌نویس خودکار، بازبینی نهایی، نوار پیشرفت، پیگیری وضعیت پرونده با کد ملی/موبایل.
- **آزمون شخصیت‌شناسی (MBTI)** با ۲۸ سؤال دوگزینه‌ای بر پایهٔ فرم رسمی شرکت: تحلیل کامل (تیپ، گروه، درصد محورها، نقاط قوت، ریسک، تناسب شغلی). **نتیجه هرگز به داوطلب نمایش داده نمی‌شود** و فقط در پروندهٔ داوطلب برای کارشناسان منابع انسانی/مدیریت است.
- ارزیابی داوطلب، یادداشت‌ها، تغییر مرحله، تبدیل داوطلب به **کارمند** با پروندهٔ پرسنلی کامل.

### کارکنان، آموزش، حضور و غیاب
- پروندهٔ کارمند (~۸۵ فیلد)، واحد سازمانی، عنوان شغلی، قراردادها، مدارک، **چارت سازمانی**، تاریخچهٔ رویدادها.
- آموزش: کتابخانهٔ دوره‌ها (خریداری/داخلی)، تخصیص به کارمند، پیشرفت، آزمون، **گواهی‌نامه**، درخواست‌های آموزشی.
- حضور و غیاب: مرخصی‌ها و مانده مرخصی، اضافه‌کاری، مأموریت، تعطیلات رسمی، کارکرد روزانه.

### حقوق و دستمزد
- دوره‌های حقوقی، محاسبهٔ خودکار بر پایهٔ قانون کار و **جدول مالیات ۱۴۰۴** (با معافیت، پله‌ها، بیمهٔ ۷٪/۲۳٪/۳٪، بن، مسکن، تأهل، اولاد، سنوات، اضافه‌کاری، شب‌کاری، تعطیل‌کاری).
- اقلام **دستی (مزایا/کسور)** برای هر فیش: افزودن/حذف/محاسبهٔ مجدد.
- صدور **فیش حقوقی شماره‌دار با کد رهگیری** و **چاپ حرفه‌ای A4** و چاپ گروهی یک دوره، خروجی CSV دوره، اقساط و وام، تنظیمات دستمزد.
- تسویه‌حساب و **ترک کار (Offboarding)**: درخواست، مصاحبهٔ خروج، تسویه، تسویهٔ مالی نهایی.

### رفاهیات و امور اداری
- **ایاب و ذهاب**: واگن/خودرو، مسیر و ایستگاه، ظرفیت، راننده، اشتراک پرسنل، سفرها و مسافران، هزینه‌ها.
- **آشپزخانه**: منو، رزرو غذا (سلف‌سرویس)، ثبت حضور در وعده، انبار و موجودی، هزینه‌ها.
- **انتظامات**: نگهبانی، شیفت، گشت، رخداد، دفتر ورود و خروج ارباب‌راجع، برگهٔ تردد.
- **رفاه**: امکانات و رزرو، درخواست‌های رفاهی، رویدادها، بیمهٔ تکمیلی.
- **امور شرکتی**: مجوزها و تمدیدها، شرکت‌های دانش‌بنیان، دارایی‌های فکری، سهام‌داران، هیئت‌مدیره، مجامع، سرمایهٔ شرکت، امور ثبتی و حقوقی، قراردادها.
- **عملیات اداری**: وظایف، درخواست‌های پرسنلی، اعلان‌ها، دارایی‌ها، نامه‌ها و قالب نامه، پیام‌رسانی پیامکی، شاخص‌ها (KPI)، ارزیابی عملکرد، گزارش‌ها.

### زیرساخت
- **نصب از مرورگر**: `/install` (بررسی پیش‌نیازها، اتصال MySQL، تعیین مدیر کل، ساخت جداول و داده‌های اولیه).
- سازگاری **MySQL/MariaDB** (cPanel) و **SQLite** (اجرای آزمایشی بدون پایگاه‌داده).
- **پشتیبان‌گیری/بازیابی** از مرورگر + تولید فایل‌های SQL برای نصب دستی + **کرون تحت وب** (یادآورها و پشتیبان).
- سازگار با موبایل، طراحی حرفه‌ای RTL، حالت روشن/تاریک، جست‌وجوی سراسری، دسترس‌پذیری (ARIA).

## 🚀 نصب روی cPanel (بدون SSH)

1. **آپلود بسته**: فایل `dist/minihrm-cpanel-1.0.0.zip` یا محتوای مخزن را در File Manager در پوشه‌ای مانند `nodeapps/minihrm` آپلود و Extract کنید.
2. **ساخت پایگاه‌داده**: cPanel → *MySQL Databases* → یک دیتابیس و کاربر بسازید و کاربر را با دسترسی `ALL PRIVILEGES` به دیتابیس متصل کنید.
3. **ساخت برنامهٔ Node.js**: cPanel → *Setup Node.js App* →
   - Application root: پوشهٔ Extract‌شده
   - Application startup file: `server.js`
   - Node.js version: **۱۸ یا بالاتر**
   - سپس دکمهٔ **Run NPM Install** را بزنید و در پایان **Restart** کنید.
4. **نصب از مرورگر**: دامنه را باز کنید؛ در صورت نصب‌نشده بودن به `/install` می‌روید:
   - اطلاعات پایگاه‌داده MySQL را وارد و «آزمایش اتصال» بگیرید،
   - نام کاربری/گذرواژهٔ **مدیر کل** را تعیین کنید،
   - دکمهٔ نصب را بزنید تا جداول و داده‌های اولیه ساخته شود.
5. **ورود**: با همان کاربر مدیر وارد شوید و از «تنظیمات» اطلاعات شرکت، پیامک و ماژول‌ها را تنظیم کنید.

> اگر می‌خواهید بدون MySQL آزمایش کنید، در گام ۳ گزینهٔ *حالت آزمایشی (SQLite)* را انتخاب کنید (پوشهٔ `storage` باید قابل نوشتن باشد).

### نصب محلی (توسعه)
```bash
npm install
npm start           # http://localhost:3000  →  /install
npm run dev         # اجرای خودکار با تغییر فایل‌ها
npm run migrate     # ساخت جداول + تولید فایل‌های SQL در پوشهٔ sql/
npm run seed        # داده‌های اولیه (نقش‌ها، مجوزها، ماژول‌ها، فرم استخدام، جدول مالیات)
npm run reset       # پاک کردن جدول‌ها (فقط آزمایشی — CONFIRM=YES)
npm run zip:cpanel  # ساخت بستهٔ نصب cPanel در پوشهٔ dist/
```

### کرون (Cron Jobs در cPanel)
- یادآورها: `https://YOUR-DOMAIN/settings/reminders/cron?token=کلید`
- پشتیبان‌گیری: `https://YOUR-DOMAIN/settings/backup/cron?token=کلید`

کلید امنیتی در «تنظیمات → یادآورها» نمایش داده می‌شود و با دکمهٔ «بازتولید کلید» قابل تغییر است. دستور نمونه:
```
/usr/bin/curl -s "https://YOUR-DOMAIN/settings/reminders/cron?token=کلید" > /dev/null
```

## 🧭 نقش‌ها و سطوح دسترسی

| نقش | دسترسی کلی |
|---|---|
| مدیر کل (`admin`) | همه ماژول‌ها و تنظیمات سامانه |
| مدیر منابع انسانی | مدیریت کامل استخدام، کارکنان، حقوق، رفاهیات و گزارش‌ها |
| کارمند منابع انسانی | انجام امور جاری، مشاهده/ویرایش پرونده‌ها بر پایهٔ مجوزها |
| کارشناس جذب | دعوت‌نامه‌ها، پرونده‌های داوطلبان، ارزیابی و آزمون‌ها |
| کارشناس حقوق و دستمزد | دوره‌های حقوقی، محاسبه، صدور و چاپ فیش |
| مدیر | مشاهدهٔ تیم، تأیید مرخصی/مأموریت و ارزیابی عملکرد |
| کارمند | سلف‌سرویس: مرخصی، فیش حقوقی، دوره‌ها، غذا، سرویس، کارکرد |
| نگهبان/انتظامات | ورود و خروج، برگهٔ تردد، رخدادهای انتظامی |
| بازرس/حسابرس | مشاهدهٔ لاگ عملیات و گزارش‌ها بدون تغییر داده |
| داوطلب شغلی | فقط فرم استخدام و آزمون مربوط به خودش |

## 🗂 ساختار پروژه

```
server.js            اجرای سرور (فایل شروع در cPanel)
app.js               فایل شروع جایگزین (برای Passenger)
src/app.js           ساخت اپلیکیشن Express (میان‌افزارها و مسیرها)
src/config.js        پیکربندی لایه‌ای + storage/config.json
src/db/              لایهٔ دوگانه MySQL/SQLite (۱۳۵ جدول، مهاجرت، دادهٔ اولیه)
src/lib/             ابزارها: اعداد/پول فارسی، تاریخ جلالی، MBTI، PDF، منبع، رایانامه‌سامانه، یادآورها
src/modules/         فهرست ماژول‌ها، نقش‌ها، مجوزها و ۸۶ منبع داده‌ای
src/routes/          مسیرها: نصب، ورود، پنل، استخدام، سلف‌سرویس، حقوق، عمومی (داوطلب) و …
src/views/           قالب‌های EJS (فارسی/RTL)
src/public/          CSS/JS/فونت/تصویر (طراحی راست‌به‌چپ)
tools/               migrate / seed / reset / ساخت بستهٔ cPanel
storage/             داده‌های محلی: config.json، پشتیبان‌ها، بارگذاری‌ها (در مخزن نیست)
sql/                 فایل‌های SQL تولیدشده برای نصب دستی (در مخزن نیست؛ در بستهٔ ZIP هست)
```

## ❓ پرسش‌های پرتکرار

**پیامک نمی‌رسد.** در «تنظیمات → پیامک» کلید IPPanel و شمارهٔ فرستنده را ثبت کنید و «آزمایش ارسال» بگیرید؛ تا تنظیم نشدن، در حالت SQLite کد تأیید برای آزمون روی صفحه نمایش داده می‌شود.

**رمز مدیر را فراموش کرده‌ام.** در سرور: `ADMIN_USER=manager ADMIN_PASS=NewPass@1404 npm run seed` (کاربر مدیر را به‌روزرسانی می‌کند) یا از کاربر دیگری با مجوز مدیریت کاربران، گذرواژه را بازنشانی کنید.

**چطور ماژولی را خاموش کنم؟** «تنظیمات → ماژول‌ها» → کلید فعال/غیرفعال همان ماژول. منوها، صفحه‌ها و دسترسی‌ها بلافاصله اعمال می‌شود.

**پشتیبان‌گیری چگونه است؟** «تنظیمات → پشتیبان‌گیری»: گرفتن پشتیبان (SQLite به‌صورت کپی کامل فایل، MySQL به‌صورت دستورهای INSERT)، دانلود، بازیابی و تولید فایل‌های SQL.
